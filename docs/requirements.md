# System Requirements

## Introduction

This document outlines the requirements for the Student Task Manager system. The purpose of this system is to help students manage and track tasks within a group project environment.

The system allows users to create tasks, assign them to team members, and track progress through different stages.

---

## System Overview

The Student Task Manager is a simple web-based application designed to support teamwork and task organisation.

It enables users to:
- Create tasks
- Assign tasks to team members
- Track task progress
- View task statistics

---

## Functional Requirements

The system must:

- Allow users to create new tasks
- Allow tasks to be assigned to specific team members
- Allow users to update task status (To Do, In Progress, Done)
- Allow users to delete tasks
- Display all tasks in a list
- Show task statistics in a dashboard

---

## Non-Functional Requirements

The system should:

- Be easy to use and user-friendly
- Load quickly and respond to user input
- Store data using browser localStorage
- Be accessible through a web browser
- Maintain data after page refresh

---

## Target Users

The system is designed for:

- Students working in group projects
- Teams needing simple task management
- Users who require a lightweight and easy-to-use system

---

## Scope of the System

The current system is a minimum viable product (MVP).

It includes basic task management features but does not include:

- User authentication
- Database integration
- Multi-user online access

These features can be added in future development.

---

## Conclusion

The Student Task Manager provides a simple and effective way to manage tasks within a team. It focuses on usability and essential features required for task tracking in a group environment.
